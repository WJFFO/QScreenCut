# 图标来源

## 程序图标（任务栏 / 托盘 / exe 图标）

由 `clipboard-line.svg` 与 `clipboard-fill.svg` 合成：蓝色圆角底 + 白色剪贴板，  
包含 16 / 24 / 32 / 48 / 64 / 128 / 256 七种尺寸（PNG 压缩的 ico）。

## images/fileicons 下的 SVG

| 文件                                        | 来源                                              |
| ----------------------------------------- | ----------------------------------------------- |
| `clipboard-line.svg`、`clipboard-fill.svg` | 阿里巴巴矢量图标库 iconfont.cn，图标 ID 42198811 / 42198809 |
| 其余（eraser、pencil、file-text 等）             | Tabler Icons，MIT 许可（见同目录 LICENSE）               |
| `language.svg`                            | 按 Tabler Icons 的 language 图形绘制，MIT              |

## 关于 iconfont 图标的授权

iconfont.cn 是图标素材聚合平台，单个图标库的授权由上传者设定（有的允许商用，  
有的仅限学习交流）。上面两个剪贴板图标来自图标库 ID 20073，下载时平台未提供  
该库的授权说明，正式对外分发前请到图标页确认许可，或替换为明确 MIT / Apache  
协议的图标（例如 Ant Design Icons、Tabler Icons），替换时保持文件名不变即可，  
工程无需改动。
